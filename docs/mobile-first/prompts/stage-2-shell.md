# Этап 2. Каркас, навигация, главная

Ветка: `feature/mobile-2-shell`. Файлы: `templates/base.html`, новый `core/templates/core/more.html`,
`core/templates/core/home.html`, шаблоны страниц (блоки), `static/`, `locale/`;
согласованная правка Python: view `more` в `core/views.py` и `path("more/", ...)` в `granitanalytics/urls.py`.

## Задача (ширина < 900 px)

0. **Долги этапа 1** (см. `reviews/stage-1.md`): в `scripts/ui_snapshots.py` не считать в метрике «полей < 16 px»
   `input[type=hidden|checkbox|radio|color|file]` и убрать `!important` с `font-size` полей в `app.css`;
   `min-height: var(--tap)` у полей и кнопок оставить только для < 900 px (десктоп — прежняя плотность, проверь `matrix_edit`).

1. **Верхняя плашка 52 px:** слева «назад» (только на вложенных: новый `{% block back_url %}` — чек → обозреватель
   с сохранённым `back_query`, супергруппа/группа/редактор → матрица с `period_query`, месяц сверки → сверка, документы →
   месяц, карточка кампании → список, покупки → карточка, акция → список, графики → акция, формы → список),
   заголовок экрана (новый `{% block page_title %}`, по умолчанию название приложения, с обрезкой), справа круглая кнопка
   с инициалами → `/more/#profile`. Текущие ссылки «← назад» в начале страниц на телефоне скрыть (на десктопе оставить),
   внутренний `h1` на телефоне не дублирует заголовок плашки.
2. **Нижнее меню** с safe-area: Продажи (`/sales/`) · Супергруппы (`/sales/matrix/`) · Акции (`/promos/`) ·
   Кампании (`/campaigns/`) · Ещё (`/more/`). Иконки — инлайн-SVG через `{% include "partials/icon.html" with name="..." %}`
   (простые, свои, `currentColor`, без внешних наборов). Подписи в одну строку, проверь на `ru` и `en`.
   Активный пункт — по тем же условиям `request.path`, что сейчас в `.nav`. Шапка `.topbar` с 6 ссылками, выходом и
   языком на телефоне скрыта; футер скрыт.
3. **`/more/`** — `login_required` (как всё приложение), без расчётов. Строки с иконкой и стрелкой, высота ≥ 48 px:
   «Сверка с Гранитом», «Главная», «Новая акция», «Новая кампания», «Редактор супергрупп», «Django-админка» (только
   `user.is_staff`), блок `#profile`: имя пользователя, язык (та же форма POST `set_language`), выход (POST `logout`).
   Тест в `core/tests.py`: обычный пользователь получает 200 и не видит ссылку на `admin:index`; staff видит;
   анонимного редиректит на логин.
4. **Главная на телефоне:** вместо hero и блока «MVP» — компактный список разделов-плиток (2 в ряд) с иконкой и
   одной строкой описания из `apps`. Технический блок «MVP / Architecture» — только на ≥ 900 px или убрать в `<details>`.
5. **Десктоп ≥ 900 px — как сейчас:** верхнее меню, язык, выход, футер; без нижнего меню и плашки.
6. Проставь `page_title` и `back_url` во всех шаблонах страниц. `auth_base.html` (вход/регистрация) — без меню,
   только поправить отступы, если на 390 px есть проблемы из отчёта этапа 0.
