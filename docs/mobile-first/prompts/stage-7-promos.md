# Этап 7. Акции и итоговая проверка

Ветка: `feature/mobile-7-promos`. Файлы: `promos/templates/promos/*.html`, `promos/templates/promos/picker/*.html`,
`static/`, `locale/`. JS пикера — только представление, логику добавления/удаления не менять.

## Задача

1. **Список:** вкладки активные/прошедшие (как сейчас по фильтру) — чипы; таблица → карточки (название, период, тип,
   справа «к базе ±N%» цветом, если есть). «Новая акция» — кнопка в плашке.
2. **Карточка акции:** шапка (период, базовые дни, тип, формат/каналы мелко, заметки — свёрнуты). KPI-плитки 2 в ряд,
   порядок: Факт, к базе %, к прошлому году %, Прогноз, остальные. «Пересчитать» и «Графики» — две кнопки ≥ 44 px в ряд.
   «Цели» — свёрнутый список «Товары: N ▾» + «Открыть в обозревателе». Таблица цен (8 колонок) → `.table-cards`:
   название (+ сайт/«нет связи» мелко), строка «Себест. · Розница · Акция · Маржа», строка «Остаток · Оценка заработка»;
   итог «Оценка заработка» — итоговой карточкой. Таблицы анализа по дням — `.table-cards--compact`.
3. **Графики.** Сейчас SVG рисуется сервером в `viewBox` ширины 800 (`promos/charts.py`, `WIDTH = 800`), текст 11 единиц →
   ~5 px на 390 px. Без правки Python попробуй: на < 600 px обёртка `.scroll-x` с `min-width: 640px` у `svg.chart` +
   увеличенный `font-size` подписей в `@media` + прореживание подписей оси X через CSS (`:nth-of-type`), легенда над
   графиком в 2 колонки. Тест проверяет точную строку `<svg class="chart"` — первым классом оставь `chart`.
   Если подписи всё равно нечитаемы/накладываются — не правь `charts.py`, поставь `blocked` и предложи в «Вопросах»
   вариант (например, параметр ширины/узкий макет графика в `charts.py`) с оценкой объёма — решает Иван.
4. **Форма акции:** сейчас на 390 px кнопки `[data-open=picker-granit]`/`picker-site` перекрыты `.grid` формы (этап 0) —
   первым делом убрать перекрытие и проверить, что кнопки нажимаются тапом. `promo-form` без `padding: 2rem` на телефоне, поля на всю ширину, сетка `.grid` — одна колонка.
   Таблица выбранных товаров `sel-table` → карточки CSS-ом поверх тех же `tr/td` (JS создаёт `<tr>` с 4 `<td>` —
   см. RULES.md §2), «Удалить» ≥ 44 px. «Сохранить и проанализировать» — в липкой панели (`form="promo-form"`),
   защита от двойной отправки.
5. **Пикер `<dialog>`:** на < 900 px — на весь экран (`100dvh`, safe-area), шапка и футер липкие. Дерево групп
   (сейчас колонка 300 px слева) — над результатами, свёрнутое в строку «Группа: Все ▾»; при выборе узла дерево
   сворачивается. `ul.tree-children` остаётся следующим соседом `.tree-toggle`. Строки результатов — тап по всей
   строке (уже есть в JS), чекбокс ≥ 44 px зона. Футер: «Добавить выбранные (N)» — основная на всю ширину,
   «Добавить всю группу» и «Готово» — вторичные.
6. На ≥ 900 px — как сейчас.
