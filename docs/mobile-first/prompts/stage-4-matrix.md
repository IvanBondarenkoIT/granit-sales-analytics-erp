# Этап 4. Супергруппы

Ветка: `feature/mobile-4-matrix`. Файлы: `sales/templates/sales/matrix.html`, `matrix_sg.html`, `matrix_group.html`,
`matrix_edit.html`, `static/`, `locale/`.

## Задача

1. **Матрица на телефоне.** Тулбар (scope, даты, Применить, Excel, Редактор, Обозреватель) — свёрнутая строка периода,
   как на этапе 3; Excel и Редактор — в меню «⋯» или вторичными кнопками. Строку баланса «Totals match» и бейдж сверки —
   компактно над данными.
   Вместо широкой таблицы — **вид «по магазину»**: чипы со скроллом «Все магазины · <магазин> · …» и список карточек
   супергрупп: цветная полоска слева (цвет супергруппы), название, справа сумма и кол-во; итог внизу. Переключение
   магазина — на клиенте (JS/CSS, данные уже есть в `matrix.rows[].ordered_cells`), без новых запросов и без правок view.
   Тап по карточке ведёт туда же, куда ссылка ячейки (`sales_matrix_sg` + `store=` при выбранном магазине).
   Кнопка «Таблица» показывает исходную матрицу со скроллом внутри `.scroll-x` (sticky-колонка на телефоне уже ~120 px).
   **Тест:** `sales/tests.py` проверяет `"HORECA TBILISI</th>"` и через `assertContains`, и через `assertNotContains` —
   имена магазинов в чипах **не** оборачивать в `<th>`; прогони тест и опиши в отчёте.
2. **Супергруппа / группа:** таблицы → `.table-cards--compact`, ссылки детализации — тап по карточке.
3. **Редактор супергрупп** (низкий приоритет, основной ввод — десктоп): на телефоне каждая строка — карточка с полями
   на всю ширину, цвет (`[data-color-pick]`: пикер + текст рядом), ↑↓ и «Сохранить» ≥ 44 px, «Удалить» — отдельно,
   красной вторичной кнопкой, не рядом с «Сохранить». Форма «Создать» — в `<details>` «+ Новая супергруппа».
   `form="sg-form-<pk>"` и скрытые поля не трогать.
4. На ≥ 900 px — как сейчас.

## Проверки

`python manage.py test`; `python scripts/ui_snapshots.py --name stage4 --compare stage3`. Руками: переключение магазина
в чипах меняет цифры, итог совпадает с колонкой магазина в табличном виде.
