# Этап 5. Сверка с Гранитом

Ветка: `feature/mobile-5-reconcile`. Файлы: `sales/templates/sales/reconcile.html`, `reconcile_month.html`,
`reconcile_docs.html`, `_reconcile_style.html`, `_reconcile_status.html`, `_reconcile_flag.html`, `static/`, `locale/`.

## Задача

1. **Обзор `/sales/reconcile/`:** месяцы — карточки: «Ноябрь 2026» + бейдж статуса (`rc-badge ok/warn/bad/open/partial` —
   классы не менять, их проверяют тесты), строкой ниже «Гранит · наши · разница», флаги — счётчиком «N флагов ▾»
   с раскрытием. Кнопка «Пересчитать» (только `is_staff`) — ≥ 44 px.
2. **Месяц:** длинные подсказки (`rc-hint`, `rc-note`) — одна строка + «подробнее ▾». Таблица магазинов (до 10 денежных
   колонок) → `.table-cards`: заголовок — магазин (ссылка на документы), главное — «Разница» крупно с цветом,
   ниже «Гранит (с НДС)», «Наши: товары / услуги», «Не реализовано» — 2 колонки «подпись: значение».
   Остальные колонки — в раскрытии карточки, не терять ни одной цифры.
3. **Документы магазина:** таблица → `.table-cards--compact` (документ, дата, сумма Гранит / наша / разница).
4. Тексты, которые проверяют тесты (`Месяц не закрыт`, ссылки на месяц и документы), сохранить.
5. На ≥ 900 px — как сейчас.

## Проверки

`python manage.py test` (`sales/tests.py` — сверка); `python scripts/ui_snapshots.py --name stage5 --compare stage4`.
Цель: `scrollWidth = 390` на всех трёх страницах сверки.
