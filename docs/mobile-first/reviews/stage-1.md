# Ревью: этап 1 (код 17866f4, tip 7eb751f) — принято

Проверено: дифф ветки, `report.json` stage1 vs baseline, скриншоты десктопа 1366 px (`sales_default`, `matrix_edit`).

- Цели этапа выполнены: на 390 px полей < 16 px = 0 на всех страницах, внешних запросов 0, HTMX локальный (48 КБ, 1.9.12),
  `collectstatic` уже есть в Dockerfile, `staticfiles/` в `.dockerignore` — на проде статика соберётся при сборке образа.
- Брейкпоинты только `min-width: 600/900/1200`, `max-width`-медиазапросов нет.
- Десктоп: заметно не хуже. Поля и кнопки стали чуть выше (44 px и на десктопе), `matrix_edit` вырос по высоте
  на ~19% (1543 → 1836 px). Это приемлемо, но не задумано — см. п. 2 ниже.

## Перенесено в этап 2 (п. 0 промпта)

1. `font-size: 16px !important` на всех `input/select/textarea` поставлен, чтобы метрика не считала hidden/checkbox/color.
   Надо чинить метрику, а не CSS: в `ui_snapshots.py` исключить `type=hidden|checkbox|radio|color|file`, а `!important`
   убрать (он помешает локальным стилям на следующих этапах).
2. `min-height: var(--tap)` для полей и кнопок — только < 900 px; на десктопе вернуть прежнюю плотность
   (особенно `matrix_edit`, таблицы фильтров).

## К сведению

- В 8 шаблонах остались локальные `table {}` / `.btn {}` / `.hint {}` — чистить при работе с экраном на этапах 3–7.
- `app.css` отдаётся без хэша в имени (`CompressedStaticFilesStorage`); WhiteNoise на проде кэширует такие файлы на 60 с,
  поэтому после выкладки новый CSS подтянется сам. Менять на Manifest-хранилище сейчас не нужно.
