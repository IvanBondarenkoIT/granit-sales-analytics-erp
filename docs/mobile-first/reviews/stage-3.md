1. **Карточка без отдельной кнопки.** Сейчас у каждой строки отдельный ряд с кнопкой «Чеки» / «Состав заказа»: карточка
   ~180 px, на экран помещается 2–3 строки. Сделай «растянутую ссылку»: основная ссылка строки (`.tc-primary a`, а для
   строк товара/группы — ссылка `receipts_query`) получает `::after { position:absolute; inset:0 }`, карточка
   `position: relative` — тап по всей карточке, ≥ 44 px автоматически. Колонку действия на телефоне скрыть; для строк
   товара, где в названии ссылки нет, ссылкой делается само название (тот же href, что у «Чеки»). На ≥ 900 px — как сейчас.
   Цель: 4–5 строк на экране 390×844 под фильтрами. Опиши этот приём в RULES-паттерне (отчёт → этап 7).
2. **Сводка фильтра:** «· 0 фильтров» не показывать при нуле (сейчас текст обрезается «0 …»). Счётчик — только если > 0.
3. **Пустой остаток:** если `stock_qty` нет, строку «—» на телефоне не выводить (сейчас лишняя строка в каждой карточке).
4. **KPI-плитки:** «Сумма» — главная, первой и на всю ширину; «Строки» и «Кол-во» — две под ней
   (или три в ряд, если влезают на 390 px без переноса). Сейчас третья плитка висит одна с пустым местом.
5. **Десктоп ≥ 900 px:** «Группировка» и «Сортировка» растянулись на всю ширину отдельной строкой. Верни их в сетку

   как было до этапа (текст был виден).
