## Про 500 на документах

Разобрал причину: `etl/pipeline.py::warehouse_store_routes()` бросает `ValueError("Warehouse X collides with receipt group
store X")`, а `reconcile_documents` ловит только `ProxyApiError`. На этапе 0 локальная БД была с демо-магазинами
(`seed_ui_demo`), а `.env` смотрел на **настоящий** proxy — ID складов из боевого Гранита совпали с ID демо-магазинов.
Скорее всего это артефакт смеси «демо-БД + боевой proxy», а не баг прода. Проверка для Ивана: открыть на
analytics.dimkava.ge любую страницу «Сверка → месяц → магазин». Если там тоже 500 — отдельная задача (ловить
`ValueError` во view и показывать понятное сообщение), вне mobile-first.
